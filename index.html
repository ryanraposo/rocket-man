Rocketman

Research, plan, implement, and verify software features through adaptive stages coordinated by GitHub Issues and pull requests.

Meet Rocket, your implementation copilot.

UnderstandInspect the codebase, tools, architecture, and existing work.
DecideResearch the options, set invariants, and choose a practical approach.
BuildPlan the right number of stages and carry the implementation through.
VerifyTest the result, record limitations, and keep the project status honest.

Install from a reviewed checkout

git clone https://github.com/ryanraposo/rocket-man
cd rocket-man
bash install.sh --dry-run
bash install.sh

One-line install

Available after the repository is public, Pages is enabled, and a versioned release is published.

curl -fsSL --proto '=https' --tlsv1.2 https://ryanraposo.github.io/rocket-man/install.sh | bash
The bootstrap verifies a versioned release archive and SHA-256 before handing off to the transactional installer. A same-origin checksum detects corruption; it is not independent authenticity.
