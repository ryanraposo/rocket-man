One workflow. Adaptive stages.

  1. Inspect the repository, tools, architecture, branches, and existing work.
  2. Research and define outcomes, invariants, dependencies, and verification.
  3. Choose the right number of stages for the actual feature—not a fixed template.
  4. Coordinate one parent GitHub issue and its implementation PR.
  5. Verify each stage, record limitations, and keep completed and remaining work distinct.

Install from a reviewed checkout

git clone https://github.com/ryanraposo/rocket-man
cd rocket-man
./install.sh --dry-run
./install.sh

Private repository access is required. See the repository for the canonical skill, contracts, and installer.
